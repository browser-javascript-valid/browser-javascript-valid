How to Enable JavaScript

Once you have enabled JavaScript, please reload this page.

To return to the previous page, please click your browser's "Back" button or the left arrow "←".

Google Chrome

  1. Click the "︙" icon in the top right corner and open "Settings".
  2. Go to "Privacy and security" → "Site settings".
  3. Select "JavaScript".
  4. Turn on the setting to allow JavaScript.

Microsoft Edge

  1. Click the "…" icon in the top right corner and open "Settings".
  2. Open "Cookies and site permissions".
  3. Select "JavaScript".
  4. Turn on the setting to allow JavaScript.

Mozilla Firefox

JavaScript is enabled by default in the standard desktop version of Firefox.

If it is not working, please check your extensions or content blockers.

Safari (Mac)

  1. Go to Safari → "Settings" (or "Preferences").
  2. Open the "Security" tab.
  3. Check the box for "Enable JavaScript".

Safari (iPhone / iPad)

  1. Open the "Settings" app.
  2. Go to "Apps" → "Safari" → "Advanced".
  3. Turn on "JavaScript".

Chrome (Android)

  1. Tap the "︙" icon in Chrome and open "Settings".
  2. Open "Site settings".
  3. Select "JavaScript".
  4. Turn on the setting to allow JavaScript.

Opera

  1. Open Opera Settings.
  2. Open Site Settings.
  3. Find the JavaScript settings.
  4. Allow JavaScript.

Brave

  1. Click the "≡" icon in the top right corner and open "Settings".
  2. Open "Shields" or "Site and Shields Settings".
  3. Find the JavaScript settings.
  4. Allow JavaScript.
